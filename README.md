# matb85.github.io

Personal site of Mateusz Bis: a one-page software-engineering profile at
[matb85.github.io](https://matb85.github.io) and a photography portfolio at
[matb85.github.io/photography](https://matb85.github.io/photography).

Built with [Astro](https://astro.build) and Tailwind CSS, deployed to GitHub Pages by
`.github/workflows` on every push to `master`.

## Development

```sh
pnpm install
pnpm imgs     # generate the webp variants in public/images (needed once, and after adding photos)
pnpm dev      # http://localhost:4321
pnpm build    # static output in dist/
```

## Where things live

| Path                             | What                                                                 |
| :------------------------------- | :------------------------------------------------------------------- |
| `src/pages/index.astro`          | The homepage: hero, about, backend rows, websites carousel, contact  |
| `src/pages/photography/`         | Album index and one page per album                                   |
| `src/components/utils/photos.ts` | Album definitions; each album maps to folders in `src/assets/photos` |
| `src/components/utils/utils.ts`  | Email and profile links used across the site                         |
| `public/resume.pdf`              | The CV linked from the homepage                                      |
| `image.config.mjs`               | The image variants generated by `pnpm imgs` and read by the viewer   |

## Photos

Source JPEGs live in `src/assets/photos/<folder>/`. `pnpm imgs` resizes them with sharp into
`public/images/<folder>/` (gitignored) at the widths listed in `image.config.mjs`. To add an
album, add a folder and reference it from `photos.ts`.
